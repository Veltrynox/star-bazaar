Sun crop tool

How to use. 1) Pick a sheet tab. 2) Line the grid up with the cells: drag the canvas to move the whole grid, drag the green dot (top-left of cell 0,0) to move it exactly, the blue dot (bottom-right of cell 0,0) to set the cell size, the pink dot (top-left of cell 1,1) to set the gap. Or type numbers. Zoom in to see the dark separator lines. 3) Check the two previews below the canvas. 4) Press Confirm crop for the sheet. Do this for all three sheets. 5) Press Download crop.json and save the file as tools/sun_crop/crop.json. Then the cutting tool can run. All numbers are pixels of the source sheet. Confirmed values are also kept in this browser (localStorage).
