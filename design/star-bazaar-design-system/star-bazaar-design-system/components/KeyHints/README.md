# KeyHints

A quiet row of map controls in the bottom-left corner, so the player never has to guess how to move the camera.

- Keys are `.ds-kbd` caps (mono 11px, `line-200` border with a 2px bottom edge); mouse actions are plain words.
- Order: Wheel Zoom · WASD Pan · Right-drag Orbit · Space Pause · K Skills · Esc Menu. On the game screen Space is left out here, because the run-state control already shows it.
- Text is `ink-subtle`: it's reference, not a call to action. Consider hiding it after the tutorial cycles.
