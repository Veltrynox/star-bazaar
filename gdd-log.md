2026-10-28 (economy-designer, rarity proposal for planet FX): planets.json has no stat but base_prices, so rarity is computed, no new key. For planet p, take every profitable one-way route touching p (source or destination) in the same system, margin = destination sell - source buy; M(p) = mean of those margins. rarity(p) = (M(p) - min M) / (max M - min M) over the system's planets, 0.5 if all equal. Current system 1: Voltara 15 -> 0.5, Tillam 14 -> 0.0, Ashgate 16 -> 1.0. Purple = rarity near 1. If the owner wants hand-set values later, add an optional "rarity" key per planet; not added now.
